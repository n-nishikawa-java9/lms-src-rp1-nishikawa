第1問 【Java】

下記の文中の（　）内にあてはまる単語の組み合わせとして、正しいものはどれか。

Javaでは、（ ① ）というソフトウェアを使用して、ソースファイルからクラスファイルを作成する。そして、（ ② ）というソフトウェアを使用して、クラスファイルの内容を機械語に変換し、プログラムを実行する。

回答
  • 1.　　①：ソースコード、②：バイトコード
  • 2.　　①：バイトコード、②：ソースコード
  • 3.　　①：コンパイラ、②：インタプリタ（Java仮想マシン）
  • 4.　　①：インタプリタ（Java仮想マシン）、②：コンパイラ

【不正解】　正解は 3 です

  • 『やさしいJava 第6版』 P3、8～10
    大半のプログラミング言語ではコンパイラ、もしくはインタプリタのいずれかを使用してプログラムを実行します。
    それに対して、Javaではコンパイラとインタプリタによる2段階での処理を通してプログラムが実行されます。
    なお、Javaのインタプリタのことを「Java仮想マシン（Java Virtual Machine、またはJVM）」と呼びます。
    以上のことから、選択肢3が正解です。

第2問 【Java】

Javaのクラスファイルが持つメリットとして正しいものはどれか。

回答
  • 1.　　Java以外の言語を実行させるためのソフトウェアでもJavaのプログラムを実行できる。
  • 2.　　OS環境に依存せずプログラムを実行できる。
  • 3.　　Windows環境でのみプログラムを実行できる。
  • 4.　　Windows環境以外でのみプログラムを実行できる。

【不正解】　正解は 2 です

  • 『やさしいJava 第6版』 P13～14
    大半のプログラミング言語では、プログラムの開発環境と実行環境が一致していないと実行できません。。
    それに対して、Javaのコンパイラによって作成されたクラスファイルは、Javaが実行可能であればどの環境でも実行可能です。環境に依存しない点はJavaの大きな強みでもあります。
    以上のことから、選択肢2が正解です。

第3問 【Java】

下記の文はどのような処理を行うためのものか。正しいものを選べ。

System.out.println()

回答
  • 1.　　コンソール中で文字を入力できるようにする。
  • 2.　　コンソール上に文字列を出力する。
  • 3.　　コンソール上に写真画像を表示する。
  • 4.　　コンソール上を自動的に閉じる。

【正解】

第4問 【Java】

main()メソッドに関する説明として正しいものはどれか。

回答
  • 1.　　プログラム起動時にmain()メソッド内に記述した文が最初に実行される。
  • 2.　　main()メソッドのブロックは、クラスブロックの外側に記述しなければならない。
  • 3.　　main()メソッドのブロックは、" [ " と " ] " で囲むかたちで表記する。
  • 4.　　main()メソッドの記述は省略可能であり、実行したい文をクラスブロック内に直接記述することもできる。

【正解】

第5問 【Java】

エスケープシーケンスに関する説明として正しいものはどれか。

回答
  • 1.　　$マークとアルファベット1文字を組み合わせて、1つの文字リテラルとして扱われる。
  • 2.　　改行や水平タブを特殊文字として文字列中に記述できる。
  • 3.　　文字列を出力する際には、エスケープシーケンスも必ず記述しなければならない。
  • 4.　　エスケープシーケンスの表記に使用する記号は、文字として出力することができない。

【正解】

第6問 【Java】

Javaにおける変数に関する説明として正しいものはどれか。

回答
  • 1.　　一度宣言した変数の型は処理の途中で自由に変更できる。
  • 2.　　変数は、宣言の処理を省略しても使用できる。
  • 3.　　1つの変数の中には、複数の値を保存できる。
  • 4.　　変数は、何らかの値を保存するための入れ物として使用する。

【不正解】　正解は 4 です

  • 『やさしいJava 第6版』 P44～51
    プログラムは計算途中の情報をメモリ上に保存しないと、その情報を後で利用することができません。そして、メモリ上には複数の情報を保存できるため、それぞれの情報が何のことなのかを識別する必要があります。そこ情報を識別して保するために利用するのが変数です。そのため、選択肢4が正解です。
    ちなみに、変数を利用するためには、事前にその変数を宣言しないといけません。そのため、選択肢2は不正解です。また、変数の型は1度宣言したら変更できないため、選択肢1は不正解です。
    他のプログラミング言語でも同様ですが、1つの変数の中には1つの値しか保存できません。そんため、選択肢3は不正解です。

第7問 【Java】

以下の文はどのような処理を行っているか。正しいものを選べ。

int number;
number = 10;

回答
  • 1.　　1行目では、整数型（number）の変数intを宣言している。2行目では、number型の上限値を10に指定している。
  • 2.　　1行目では、浮動小数点数型（int）の変数numberを宣言している。2行目では、変数numberに10という値を代入している。
  • 3.　　1行目では、整数型（int）の変数numberを宣言している。2行目では、変数numberに10という値を代入している。
  • 4.　　1行目では、整数型（int）の変数numberを宣言している。2行目では、変数numberの値が10と等しいかどうかを比較している。

【正解】
